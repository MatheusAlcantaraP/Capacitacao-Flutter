# ☕ AsiCoffee

Aplicativo mobile desenvolvido em **Flutter** para a cafeteria fictícia **AsiCoffee**, com foco na construção de interfaces visuais, componentização de widgets e gerenciamento básico de estado.

## 📱 Funcionalidades

- Listagem de produtos da cafeteria.
- Exibição de imagem, nome, categoria e preço.
- Botão de favorito nos itens.
- Filtro de itens por categoria.

## 📚 Conceitos Aplicados

### Modelagem de Dados

Foi criada a classe `CoffeeItem` para representar os produtos do cardápio, contendo:

- Nome
- Preço
- URL da imagem
- Categoria
- Status de favorito

### Componentização

A interface foi dividida em widgets reutilizáveis, facilitando a organização e manutenção do código.

### Gerenciamento de Estado

O controle de favoritos foi implementado utilizando `StatefulWidget` e `setState()`, permitindo a atualização dinâmica da interface.

## 🚀 Tecnologias Utilizadas

- Flutter
- Dart
